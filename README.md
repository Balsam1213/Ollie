# Ollie 🐣

基于 ESP32-S3 的桌面电子宠物：不追求完整的宠物轮廓，核心只有一块 0.96" OLED 上的一张脸——眼睛和嘴巴全部用代码画出来，靠表情、数值和互动让人感觉它"活着"。

**v1（离线版，插电即玩）玩法**：
- 表情动画：自动眨眼、眼珠乱瞟；平静 / 开心 / 饥饿 / 困倦 / 睡眠五种表情
- 按键互动：喂食、抚摸两个轻触开关，触发开心表情 3 秒 + 蜂鸣器两声
- 三项数值：饱食度 / 心情 / 精力，醒着每分钟各掉 1 点，断电不丢；睡觉回精力
- 昼夜感知：持续变暗 10 秒自动入睡（闭眼 + Zzz + 屏幕变暗），变亮自动醒来
- 心情灯：板载 RGB 随心情变色（青绿呼吸 / 黄色常亮 / 橙红慢闪 / 睡眠深蓝 / 互动粉色）

本 README 是**从零做出实机的完整操作手册**：清单 → 接线 → 烧录 → 自测 → 标定 → 排查。深文档见 [docs/](docs/README.md)，开发日志见 [devlog/](devlog/README.md)。

## 二、接线

### 接线总表（照着插，一行一根线）

| 从 | 到 | 建议线色 | 说明 |
|---|---|---|---|
| OLED **VCC** | 3V3 电源轨 | 红 | |
| OLED **GND** | GND 电源轨 | 黑 | |
| OLED **SCL** | 板上 **GPIO 9** | 黄 | |
| OLED **SDA** | 板上 **GPIO 8** | 蓝 | 别和 SCL 接反，接反点不亮屏 |
| 光敏 **VCC** | 3V3 电源轨 | 红 | |
| 光敏 **GND** | GND 电源轨 | 黑 | |
| 光敏 **AO 或 DO** | 板上 **GPIO 1** | 橙 | 4 针模块接 **AO**；3 针 LM393 模块接 **DO**（Config.h 已默认 DO 模式）。另一只信号脚悬空不接 |
| 蜂鸣器 **+（长脚/红线）** | 板上 **GPIO 15** | 绿 | |
| 蜂鸣器 **−（短脚/黑线）** | GND 电源轨 | 黑 | |
| 喂食开关 **脚A** | 板上 **GPIO 4** | 白 | |
| 喂食开关 **脚B** | GND 电源轨 | 黑 | |
| 抚摸开关 **脚A** | 板上 **GPIO 5** | 灰 | |
| 抚摸开关 **脚B** | GND 电源轨 | 黑 | |
| 板 **3V3 引脚** | 面包板 3V3 电源轨 | 红 | 给所有模块供电 |
| 板 **GND 引脚** | 面包板 GND 电源轨 | 黑 | 公共地 |

- **心情灯不用接**：就是板子上那颗彩色 LED（固件驱动 GPIO48）
- 四脚轻触开关的 A/B 两脚**取对角位置**的两个脚，保证跨在开关内部触点两侧（同侧两脚是内部直通的）
- 开关不需要外接电阻，代码里用了内部上拉
- OLED 和光敏模块一般板载上拉/分压电阻，无需外接元件

### 通电前检查（1 分钟，能省 1 小时排错）

1. 数一遍：每根线两端是否都插紧、和总表一致
2. 重点看 **3V3 轨和 GND 轨没有短接**（红黑没有交叉）
3. OLED 的 SDA/SCL 没有互换（最容易犯）
4. USB 线插板上**标 USB 的口**（不是 UART 口），另一端插电脑

## 三、软件安装与烧录

### 路线 A：Arduino IDE 2.x（推荐，步骤最短）

1. **装 IDE**：[arduino.cc/en/software](https://www.arduino.cc/en/software) 下载 Arduino IDE 2.x 安装
2. **装 ESP32 板级支持**：左侧"开发板管理器"图标 → 搜索 `esp32` → 安装 **esp32 by Espressif Systems**（新版本直接搜得到，无需额外网址）
3. **装显示库**：左侧"库管理器"图标 → 搜索 `SSD1306` → 安装 **Adafruit SSD1306**，弹窗问依赖时选 **Install all**（会连带装 Adafruit GFX）
4. **打开工程**：把整个 Ollie 文件夹拷到 `文档/Arduino/Ollie/`（保持 Ollie.ino 和所有 .h/.cpp 同一层），双击 `Ollie.ino` 打开
5. **选板子和关键选项**（Tools 菜单，逐项核对）：

   | 菜单项 | 选择 |
   |---|---|
   | Board | **ESP32S3 Dev Module** |
   | **USB CDC On Boot** | **Enabled** ← 不开这条串口/日志没有任何输出，新手第一大坑 |
   | Flash Size | **16MB** |
   | PSRAM | **OPI PSRAM** |
   | Partition Scheme | **16M Flash（APP ≥3MB 的那项，名字以菜单实际为准）** ← v2 固件已超 1.2MB，默认 4MB 方案的 APP 分区会不够用 |
   | Port | 插上板子后出现的新 COM 口 |

   > Port 里没有新 COM 口 → 装 USB 串口驱动：多数板子是 [CP210x 驱动（Silicon Labs 官网）](https://www.silabs.com/developer-tools/usb-to-uart-bridge-vcp-drivers)，部分国产板是 CH343（搜"CH343 driver"）
6. **编译上传**：点左上角 →（Upload）按钮。首次编译几分钟属正常
7. **看串口日志**：右上角放大镜图标（Serial Monitor）→ 右下角波特率选 **115200**

> **上传连不上？**（报错 `Connecting......` 后 `No serial data received` / `Failed to connect`——芯片没进下载模式，与代码接线无关）三步救：
> 1. **手动进下载模式**：按住 BOOT → 短按一下 RST(EN) → 松开 RST → 松开 BOOT → 点上传
> 2. **换 COM 口上传**：板上 USB 口负责看日志，**COM 口（串口芯片）上传最稳**（硬件自动复位进下载模式）；两口的 COM 号在 Port 菜单里不同，换口后要重选。分工：上传用 COM，看日志用 USB（CDC 日志走 USB 口）
> 3. 仍失败：换**数据线**（充电线不行）并直插电脑、Upload Speed 降到 115200、设备管理器核对端口号

### 路线 B：VS Code + PlatformIO（备选）

装好 PlatformIO 插件后打开本项目文件夹（`platformio.ini` 已配好 N16R8 参数和库依赖），底部状态栏 →（Upload）烧录，插头图标（Serial Monitor）看日志。命令行等价：

```bash
py -m platformio run -t upload    # 编译并烧录
py -m platformio device monitor   # 串口日志 115200
```

## 四、首次上电：应该看到什么

1. **屏幕**：亮起显示大字 "Ollie" 约 1 秒 → 进入平静表情：两只白色圆角矩形眼睛（内有黑瞳孔）+ 微笑弧线
2. **串口**（115200）应打印：

   ```
   === Ollie v1 ===
   [boot] 饱食=80 心情=80 精力=80
   ```

   （首次上电三项都是 80）
3. **板载 RGB**：心情 80 → 青绿色缓慢呼吸
4. **动起来**：静置观察，每 2–6 秒自动眨一次眼，每 3–8 秒眼珠往一边瞟一下再回来
5. 屏幕没亮但串口有 `[error] OLED 初始化失败` → 见排查表第 2 条

以上都正常，说明 M1（点屏）+ M2（表情）就绪。接着按第五节清单把其余功能过一遍。

| # | 操作 | 预期 |

## 六、光敏标定（必做一次，约 10 分钟）

**先确认你的模块类型**（代码默认按 3 针 DO 模块配置）：

- **3 针模块（VCC GND DO，LM393）**：跳过下面第 1–4 步的阈值部分，按"DO 标定"操作
- **4 针模块（多一个 AO）**：把 `Config.h` 的 `LIGHT_USE_DO` 改成 `0` 后按"AO 标定"操作

### DO 标定（3 针 LM393，只需标极性）

1. `Config.h` 置 `LIGHT_CALIBRATE 1`（确认 `LIGHT_USE_DO 1`），烧录
2. 串口每 0.5 秒打印：`[light-cal] DO=x（暗电平应为 y）`
3. **手完全遮住**模块看打印值、**台灯照**着再看打印值——两种环境打印的 DO 值应该不同
4. "暗"时打印 **DO=1** → 保持 `LIGHT_DO_DARK_LEVEL 1`；打印 **DO=0** → 改成 `0`。（阈值大小由模块板上的蓝色电位器调：先用默认，若睡/醒太灵敏或太迟钝，用螺丝刀微调电位器）
5. `LIGHT_CALIBRATE` 改回 `0`，重新上传，做第五节第 4–7 项测试
6. 记录：暗电平 `____` / 电位器位置 `____`（日期：____）

### AO 标定（4 针模块）

1. `Config.h` 置 `LIGHT_USE_DO 0`、`LIGHT_CALIBRATE 1`，烧录
2. 串口每 0.5 秒打印：`[light-cal] ADC=xxxx（暗<800 亮>2000）`
3. 分别记录四种环境的 ADC 值（各记 10 个左右取范围）：
   - 白天正常摆放（应醒）
   - 傍晚/阴天（应醒）
   - 夜晚室内灯光（按你平时使用场景决定该醒还是该睡）
   - **手完全遮住**（应睡）
4. 定阈值（在 `Config.h`）：
   - `LIGHT_DARK_ADC` = "应睡"环境读数的**最大值**再留 10% 余量
   - `LIGHT_BRIGHT_ADC` = "应醒"环境读数的**最小值**再留 10% 余量
   - 两个阈值之间就是防抖动的迟滞带，间隔越大越稳
5. `LIGHT_CALIBRATE` 改回 `0`，重新上传，重测第五节第 4–7 项
6. 标定完把最终数值记到此处：暗阈值 `____` / 亮阈值 `____`（日期：____）

> 两种模式的差别：AO 有硬件迟滞（双阈值）+ 软件防抖；DO 只有单一阈值，固件用"变暗 10 秒确认 + 变亮 2 秒确认 + 连续一致滤波"做软件补偿，效果接近，正常使用无感。

## 九、故障排查表

| 症状 | 原因 → 解法 |
|---|---|
| 串口监视器完全没输出 | USB CDC On Boot 没开 → 工具菜单打开后重烧；或波特率不是 115200 |
| Port 里找不到板子 | 缺 USB 串口驱动 → 装 CP210x / CH343 驱动（见第三节第 5 步） |
| 上传失败/超时（No serial data received） | 芯片没进下载模式 → 见第三节"上传连不上？"三步救：手动下载模式 / 换 COM 口 / 换数据线 |
| 烧录成功但 COM 口看不到日志 | 正常：开了 USB CDC，日志走 **USB 口**——串口监视器换插 USB 口的那个 COM 号 |
| 屏幕全黑，串口报 OLED 初始化失败 | SDA/SCL 接反 → 对调；VCC 没接 3V3；地址不是 0x3C → 把 `Config.h` 的 `BOOT_I2C_SCAN` 改 1 烧录扫描，按串口报的地址改 `OLED_ADDR` |
| 屏亮但显示雪花/横纹 | I2C 线太长/接触不良 → 重插杜邦线 |
| 两声哔哔变成长鸣 | 买成有源蜂鸣器 → 换无源 |
| 板载 RGB 不亮或颜色不对 | 你的板子批次 RGB 在 GPIO38 → `Config.h` 的 `PIN_RGB_LED` 改 38 |
| 按键没反应 | 四脚开关选错了同侧两脚（内部直通）→ 换成对角两脚 |
| 遮光立刻睡、见光立刻睡反复横跳 | AO 模式：阈值带太窄 → 重做第六节标定；DO 模式：微调模块上电位器分开睡/醒触发点 |
| DO 模块睡醒反应与预期相反 | 极性没标对 → 按第六节"DO 标定"改 `LIGHT_DO_DARK_LEVEL` 为 0 或 1 |
| 断电后数值丢了 | 存档写在每分钟结算时，互动后马上断电会丢最后一次加成，属预期；重启后一直回 80 才异常（NVS 坏） |
| 接了某外设后死机/开不了机 | 线误接到 GPIO35/36/37（N16R8 的 PSRAM 占用）或 strapping 脚 → 按第二节总表核对接线 |

**万能三板斧**：接线对着第二节总表逐根核对 → `BOOT_I2C_SCAN` 扫总线 → 串口 115200 看日志（几乎所有问题日志里都有线索）。

## 十、网页聊天（v2.0，已内置）

Ollie 现在带联网聊天能力，**不配置也完全不影响离线玩法**（断网自动回纯离线模式，心情灯蓝闪一次提示）。

**首次配置（5 分钟）**：

1. 给 Ollie 上电，它会开出热点 **`Ollie-Setup`**（密码 `ollie12345`）
2. 手机连这个热点，会自动弹出配置页（没弹就浏览器打开 `http://192.168.4.1`）
3. 填家里 WiFi 的名称密码 + **大模型 API Key**（OpenAI 兼容接口，默认预填 DeepSeek 的地址，用其他家改"接口地址"即可），保存——Ollie 自动重启连网
4. 之后用同一 WiFi 的手机浏览器打开 **`http://ollie.local`** 就能打字聊天
5. 想换 Key/换模型/改 WiFi：聊天页右上角"设置"

**行为说明**：回复通过大模型生成，返回的情绪（happy/calm/hungry/sleepy）会直接驱动 OLED 表情；服务异常或断网时聊天不可用，Ollie 自动回到离线宠物模式，来电自动恢复。API Key 只存在 Ollie 本机（NVS），不进代码仓库。

> 联网功能需实机验证（仿真器对 WiFi 支持有限）；验证要点见 devlog/TODO.md v2.0 组。

### 调试开关（都在 Config.h）

| 开关 | 作用 |
|---|---|
| `LIGHT_USE_DO` | 光敏硬件选择：1=3 针 DO 模块（默认），0=4 针 AO 模块 |
| `LIGHT_DO_DARK_LEVEL` | DO 模式"暗"的电平（标定，见第六节） |
| `DEBUG_FAST_DECAY` | 数值 1 点/秒（正常 1 点/分钟），快速看全程 |
| `LIGHT_CALIBRATE` | 500ms 打印光敏读数（标定用） |
| `BOOT_I2C_SCAN` | 只跑 I2C 扫描（排 OLED 接线用） |
| `PET_WAKE_ENABLED` | 睡觉时按抚摸键唤醒的彩蛋，默认关 |
| `OLLIE_DEBUG 0` | 关全部串口日志 |
