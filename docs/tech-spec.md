### 1.2 引脚分配（v1 定稿）

| 功能 | GPIO | 说明 |
|---|---|---|
| OLED SDA / SCL | 8 / 9 | S3 Wire 默认引脚 |
| 按键·喂食 / 抚摸 | 4 / 5 | 另一脚接 GND，INPUT_PULLUP |
| 光敏 AO/DO | 1 | 同一引脚二选一：4 针模块接 AO（模拟），3 针 LM393 模块接 DO（数字，Config.h `LIGHT_USE_DO=1` 默认）。**必须 ADC1（GPIO1–10）**：v2 开 WiFi 后 ADC2 模拟功能不可用 |
| 蜂鸣器 | 15 | LEDC PWM。**电磁式无源蜂鸣器必须串 100Ω 电阻**（直驱 60–100mA 超过 GPIO 40mA 规格，实测触发闩锁整机掉电） |
| 心情灯 | 48 | 板载 WS2812（个别批次 GPIO38，以丝印为准） |

**刻意避开**：GPIO0/3/45/46（strapping）、19/20（USB D+/D−）、**35/36/37（N16R8 八线 PSRAM 占用）**、11–18 不安排模拟功能（ADC2），其中 **12/13/14/16/17/18 留空给 v2 I2S 音频**。

## 2. 软件架构

### 2.1 模块划分

| 模块 | 职责 | 关键约束 |
|---|---|---|
| Ollie.ino | 入口 + 毫秒调度器 + 联网状态编排 | 全非阻塞；调度周期 33ms 渲染 / 20ms 按键+网页 / 500ms 光敏+WiFi / 60s 结算（DEBUG 时 1s） |
| Config.h | 所有引脚/阈值/节奏/开关 | 项目唯一的"魔法数字"集中地 |
| PetState | 醒/睡状态机、表情优先级、事件分发 | 唯一允许改 asleep 状态的地方 |
| Stats | 三项数值 + NVS 存档 | 数值读写只经此类；有变化才落盘 |
| Face | 表情绘制与动画 | 对外仅 `setBase` / `setExpression(Emotion, holdMs)`，**与触发源解耦（v2 已兑现）** |
| Buttons / Buzzer / LightSensor / MoodLight | 输入输出外设 | 各自封装消抖/时序/迟滞/渐变，不越界 |
| ChatLogic | v2 聊天纯逻辑：prompt/JSON 转义与提取/回复解析/情绪映射 | **零 Arduino 依赖**，PC 单测与固件共用 |
| NetConfig | v2：WiFi 连接状态机、配网热点门户、mDNS、凭据 NVS | 不持有网页服务；状态变化由 Ollie.ino 编排 |
| LLMClient | v2：LLM 调用 | FreeRTOS 任务（core 0）跑 HTTPS，渲染不受 1–3s 延迟影响；结果带序号保留 |
| WebChat | v2：局域网聊天页/设置页/三个 API | 异步应答（POST 立即 202 + 轮询取结果），handler 不做长阻塞 |
| Dialog | v1.2：台词驱动器（事件/阈值跨越/闲聊/冷落四类触发 + 随机选句防重复） | 台词池在 DialogLines.h（inline 变量），改台词后必须重跑 tools/genfont.py 重新生成字库 |
| DialogFont | v1.2：生成的 12×12 中文字库（91 字形 ≈3KB，genfont.py 产物） | 只读生成物，手改会被覆盖 |

### 2.2 核心规则

- **状态机**：醒 ⇄ 睡（变暗≥10s 入睡 / 变亮醒）；醒时表情优先级 = 临时开心3s > 饥饿(饱食<30) > 困倦(精力<30) > 平静
- **数值**：醒着三项各 −1/分钟；睡眠精力 +2/分钟、其余停；喂食 饱食+20/心情+4；抚摸 心情+15；0–100 截断；互动立即生效、下次结算落盘
- **昼夜判定**（双硬件模式，`Config.h` 的 `LIGHT_USE_DO` 切换）：
  - AO 模式：8 次滑动均值；迟滞（<800 判暗、>2000 才判亮，中间维持原态）；持续变暗 10s 确认入睡；变亮立即醒
  - DO 模式（3 针 LM393，无硬件迟滞）：连续两次电平一致才采纳 + 持续变暗 10s 确认入睡 + 持续变亮 2s（`WAKE_CONFIRM_S`）才醒；极性由 `LIGHT_DO_DARK_LEVEL` 标定
- **渲染**：30fps 限帧；几何初始值（眼中心 (40,22)/(88,22) 24×28 圆角矩形、嘴中心 (64,46)）在 Face.cpp 顶部；眨眼 180ms 三段；防灼伤每 30s 整脸漂移 1px；睡眠 `display.dim(true)`

## 3. 性能与实测基线（2026-10-30，含 v2.0 联网 + v1.2 台词，PlatformIO release 构建）

| 指标 | 实测 | 预算 |
|---|---|---|
| RAM | 16.2%（53,124 / 327,680 B） | <60% |
| Flash | 40.5%（1,352,398 / 3,342,336 B） | <50% |
| 帧率 | 30fps（全帧刷新 I2C 400kHz ≈23ms；聊天走独立任务不占帧） | ≥25fps |

Flash 增长说明：v1 基线 13% → v2.0 后 40%（WiFi/TLS 栈 ~900KB）→ 台词字库 +0.2%，均属预期。

## 5. v2 技术预留

1. I2S 六脚预留（见 1.2）：INMP441 麦克风 ×3 + MAX98357A 功放 ×3

3. Stats 集中：云端同步只动 Stats 模块
4. 环境参数已按 N16R8 配置（`qio_opi` + 16MB Flash）
