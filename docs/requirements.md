# 需求规格 · requirements

产品定位：基于 ESP32-S3 的桌面电子宠物。核心是 0.96" OLED 上的一张脸，眼睛和嘴巴全部代码绘制，靠表情、数值和互动让人感觉它"活着"。v1 完全离线、插电即玩；联网能力按阶段叠加，**离线体验是任何时候都不能破坏的底线**。

## v1 功能需求（已实现，待实机验收）

| 编号 | 需求 | 验收标准 |
|---|---|---|
| FR-01 | 表情动画：平静/开心/饥饿/困倦/睡眠五表情；自动眨眼（2–6s 随机）；眼珠乱瞟（3–8s 随机，±6px） | 静置观察，眨眼与瞟眼均出现；五表情可被对应条件触发 |
| FR-02 | 按键互动：喂食键（饱食+20/心情+4）、抚摸键（心情+15）；触发后开心表情 3 秒 + 蜂鸣器两声（2kHz，80-80-80ms） | 按键响应即时；快速连按不误触、不漏按 |
| FR-03 | 数值系统：饱食/心情/精力 0–100，醒着每分钟各 −1；NVS 存档断电不丢 | 断电重启 3 次数值恢复；到 0 不为负、到 100 封顶 |
| FR-04 | 睡眠：精力<30 显示困倦；光敏持续变暗 ≥10s 入睡（数值停走、**精力 +2/分钟**、Zzz 动画、屏幕调暗）；变亮立即醒来 | 遮光 10s 入睡/照亮即醒，来回 5 次不横跳；睡后精力明显回升 |
| FR-05 | 表情优先级：临时开心(3s) > 睡眠 > 饥饿(饱食<30) > 困倦(精力<30) > 平静 | 又饿又困时显示饥饿脸 |
| FR-06 | 心情灯：板载 WS2812；心情≥70 青绿呼吸 / 40–69 琥珀黄常亮 / <40 橙红慢闪 / 睡眠深蓝呼吸 / 互动 3s 粉色 | 档位切换 200ms 渐变；夜间不刺眼（亮度封顶可调） |
| FR-07 | 养护屏幕与 Flash：整脸每 30s 随机漂移 1px；数值无变化不写 NVS | 长期运行无残影异常、无 Flash 磨损风险 |

**设计修正记录**：原设定睡眠仅"数值停走"，会导致精力首次归 0 后永远无法恢复（永久困倦脸）。已确认修正为睡眠回精力 +2/分钟（2026-10-25）。

**可选彩蛋**（`PET_WAKE_ENABLED`，默认关）：睡眠中按抚摸键唤醒。

## v1 非功能需求

- NFR-01 成本：硬件合计 ≤ ¥60
- NFR-02 可靠性：过夜长测无死机、无内存泄漏（串口观测 heap）
- NFR-03 兼容性：arduino-esp32 2.x / 3.x 均可编译；Arduino IDE 与 PlatformIO 双路线
- NFR-04 性能：30fps 渲写；实测 RAM 7.6%、Flash 13.0%（余量 >85%）
- NFR-05 保密：仓库不得出现任何密钥/口令（v2 API key 走 NVS + 配置页）

## v2 需求草案（AI 聊天，未立项细节）

- FR-2x1 网页聊天：局域网网页打字对话；LLM 返回 `{reply, emotion}`；情绪驱动表情
- FR-2x2 语音对话：按键说话起步；ASR/TTS 云端；后续本地唤醒词
- FR-2x3 情绪回流：聊天情绪增减心情值，与养成闭环融合
- NFR-2x1 断网降级：联网功能失效时自动回退 v1 离线模式，离线玩法零损失

## 明确不做（v1 范围外）

完整宠物轮廓/外壳、死亡机制、多宠物、手机 App、OTA——都不在 v1；新增"不做"项需在此登记，避免范围蔓延。
