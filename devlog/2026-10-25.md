## 决策

| 决策 | 理由 |
|---|---|
| 睡眠期间精力 +2/分钟（修改原设定） | 原设定精力只降不升，首次归 0 后永远挂困倦脸；让睡觉有意义 |
| 心情灯用板载 WS2812（GPIO48），不外接 | 零成本零接线，仿真与实机同款 |
| 按键扫描周期 200ms → 20ms（偏离计划表） | 200ms 会漏掉快速点按；消抖仍靠 30ms 时间窗 |
| NVS 只在数值有变化时写 | 进一步降低 Flash 磨损（原本按分钟写也已安全） |
| 去掉"强制 arduino-esp32 3.x"，Buzzer/MoodLight 加 2.x/3.x 版本垫片 | Wokwi 核心版本不可控；垫片成本≈0，双版本都能编译 |
| Wokwi diagram 布局紧凑化（元件聚拢） | 原布局 OLED 在默认视野外，自动适配视野后一屏可见全部元件 |
| 互动数值立即生效、落盘在下次结算 | 简化；代价是结算前断电丢本次加成（已记录，可接受） |
| v2 AI 聊天走"自建轻链路"，语音阶段借鉴 xiaozhi-esp32（MIT） | 保住 Ollie 养成玩法是底线；小智当零件库用 |

## 问题与坑

- **Windows `python` 是坏的商店占位符**（exit 49）：用 `py` 代替；`pip` 命令不存在，用 `py -m pip`
- **无本地 C++ 编译器**：`py -m pip install ziglang` 用 zig 自带编译器跑单测；注意加 `-target x86_64-windows-gnu` 和 `-w`（否则 zig 编 libc++ 的警告刷 5MB 屏）
- **PlatformIO 首次构建 17 分钟**：工具链下载 ~1GB，属正常；第二次起 12 秒
- **arduino-esp32 3.x LEDC API 变更**：`ledcAttach()` 替代 `ledcSetup`+`ledcAttachPin`，老教程代码编译不过 → 版本垫片
- **S3 串口无输出**：Arduino IDE 必须开 USB CDC On Boot: Enabled
- **Wokwi 串口监视器入口未找到**（新版 UI，未登录状态）：待查；行为验证改用 OLED 特写截图判定
- **Wokwi 视觉定位噪音大**：全页截图让视觉模型找元件经常认错；改为**固定取景窗口的裁剪特写**后判定稳定可靠
- **Wokwi 无障碍部件覆盖层在 shadow DOM 里**：普通 querySelector 查不到，需递归遍历 shadowRoot
